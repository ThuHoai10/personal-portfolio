## 🚀 Hướng dẫn cài đặt & khởi chạy

### Yêu cầu hệ thống
- Flutter SDK (>= 3.13.2)
- Dart SDK
- Trình duyệt Chrome hoặc thiết bị Android/iOS/máy ảo

### Các bước thực hiện

1. **Clone repository:**
   ```bash
   git clone https://github.com/ThuHoai10/personal-portfolio.git
   cd personal-portfolio
   ```

2. **Cài đặt dependencies:**
   ```bash
   flutter pub get
   ```

3. **Chạy ứng dụng:**
   - Chạy trên Web (Chrome):
     ```bash
     flutter run -d chrome
     ```
   - Chạy trên thiết bị di động / máy ảo:
     ```bash
     flutter run
     ```
